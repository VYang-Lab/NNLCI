# Upload package manifest

This package reorganizes the validated NNLCI workflows into four problem
directories. It intentionally excludes Python environments, IDE caches,
Visual Studio build intermediates, smoke-test weights, and duplicate root-level
legacy files.

Included material:

- runnable Python, C++, and CUDA Fortran source;
- supplied and regenerated CFD/training data;
- non-smoke trained model weights;
- prediction arrays, metrics, figures, and publication plots;
- Config 3 bootstrap and processed 2D arrays;
- documentation assets and legacy documentation.

The 2D Config 3 model in this package is the two-epoch pipeline-validation
checkpoint generated from bootstrap data. It is not a publication-quality
scientific model. The supplied 1D `best_model_*.pth` files are the original
trained checkpoints used for the reported prediction metrics.

The package includes files larger than GitHub's regular 100 MB limit. The root
`.gitattributes` therefore routes arrays, weights, CFD fields, and PDFs through
Git LFS. Run `git lfs install` before the first commit to a GitHub repository.

## Presentation assets

The visual-first README opens with a 4.41-second workflow GIF and a linked
permanent PNG. LF1/LF2 now come from **independent CPU CFD solves** at 100 and
200 intervals per axis, using the existing CUDA-Fortran numerical kernels
through a serial execution adapter. The packaged 800-resolution field remains
the HF target. The GIF has brief labels and animates only sampling/signal cues;
no NNLCI output or time evolution is claimed.

New CFD fields, namelists, logs and source/compiler provenance live in
`problems/2d_riemann/data/promo_cfd/`, separate from unchanged bootstrap/training
arrays. `scripts/regenerate_promo_lf.py` runs diagnostics and both solves;
`scripts/render_gatech_promo.py` reads the saved fields. The rebuilt mechanism
has an editable SVG master, PDF and PNG; the independent-resolution comparison
also exports SVG/PDF/PNG. The existing density/pressure hero and full-domain
view still visualize the packaged HF/bootstrap source.

[gatech_provenance.json](assets/promo/gatech_provenance.json) records input/output
hashes, shared crop/scales and memory gates. The CPU solver/static render gate
is 700 MiB; GIF generation requires 1,500 MiB and uses 40 indexed frames at
1080 × 430. Below that gate, the README uses the permanent poster. No new model
training/inference occurred. CPU/GPU parity and the original HF execution log
remain unavailable; no conservation, speedup or held-out accuracy claim follows.

[Figure-tool setup](figure_tools/README.md) includes source examples and a
machine-readable export report for OpenSCAD, Graphviz, draw.io, FreeCAD,
SVG/Python and Blender. Local executables/build products are excluded.

The [Sod gallery](assets/promo/README.md#sod--packaged-checkpoint-evidence) is regenerated by
`scripts/promo_from_sod_results.py` using CPU inference from the supplied
`best_model_sod_final.pth` and raw Sod data. It includes shared-scale density
comparisons, signed density-error curves, a six-case sweep, a permanent
static strip, and P1.25 NumPy arrays. A GIF is optional and memory-gated.
[provenance.json](assets/promo/provenance.json) records source hashes and
library versions for the gallery run. Layout-only P1.25 replots use
`scripts/replot_sod_promo.py` and preserve those original hashes, recording
the saved-array hashes and renderer separately. Gallery arrays also use Git LFS.

The LF/HF concept and training-tokenization images under `docs/assets/` are
illustrative, not checkpoint benchmarks. Existing problem result/publication
figures are retained; this presentation update does not revalidate every
historical result. The primary Lax MLP checkpoint is supplied; the optional
residual branch's default `best_model_lax_resnet.pth` is absent.

Use `git lfs pull` after cloning to retrieve the actual arrays and weights.
The [documentation index](README.md) points to current workflows; legacy
documents and the superseded intro draft are not primary instructions.
